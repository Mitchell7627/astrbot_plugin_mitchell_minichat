# 主动私聊Mini（astrbot_plugin_mitchell_minichat）

> 版本 **v0.1.3** ｜ 仅支持 **aiocqhttp（QQ）私聊** ｜ MIT

> **反馈**：遇到问题请到 [GitHub Issues](https://github.com/Mitchell7627/astrbot_plugin_mitchell_minichat/issues) 提交，并附上 AstrBot 版本、插件版本和相关日志。

一个给 AstrBot 用的轻量「主动消息」插件：不用你招呼，她会自己挑时机凑过来开口。

不是定时群发，也不是关键词自动回复——她按一条加权概率曲线挑时间，结合你正在做什么、你在不在她身边，决定说什么、用什么语气。

**平台范围**：只处理 aiocqhttp 的私聊消息，群聊不生效，其他平台适配器未做验证。

---

## 它做什么

- **自己挑时间开口**：按加权曲线采样下一次说话的时间，不是固定间隔；内置四档，也能自己调。
- **知道你在干嘛**：识别吃饭、做饭、洗澡、开会、约会等 16 类事件，每类有自己的持续时长、开口加成和话术。
- **知道你在不在**：说「出门了」她会当你不在；说「到家了」她立刻贴回来；说「一起出门」「牵着手」她会记成「在一起」。
- **会催睡**：晚睡、午睡两个提醒窗口，说「等会睡」还能单独排一次；说「晚安」后进入免打扰，只有你说「醒了」才解除。
- **像人一样说话**：长消息自动切成几条短气泡，中间按字数停几秒。
- **自带面板**：任务、概率、配置三页，改参数能实时看柱形图预览，不用重启。

## 安装

要求 AstrBot **>= 4.29.0**。

1. 把插件目录放进 `data/plugins/`，或在 AstrBot 插件市场搜索「主动私聊Mini」安装。
2. 重启 AstrBot，在「插件管理」里启用。
3. 打开插件配置，在「监听的会话」里填入要服务的私聊会话：
   ```
   机器人名:FriendMessage:QQ号
   ```
   在 QQ 里给机器人发 `/sid` 可以直接拿到这串 ID。
4. 保存后插件开始排程；想立刻看效果，打开 Web 面板点「生成预览」。

> 只有 `session_list` 里的会话会被服务，其他私聊一律不管。

## 五分钟上手

1. **填会话**：见上一步。
2. **选频率**：面板「概率」页顶部四个档位，先选「默认」。
3. **试一句**：在 QQ 里说「我去洗澡了」，面板「任务」页的「当前事件」应该变成「在洗澡」。
4. **看预览**：任务页点「生成预览」，只生成不发送，可以反复试。
5. **调语气**：配置页「主动消息提示词」里改，保存即生效。

## 聊天频率：四档 + 自定义

| 档位 | 间隔范围 | 前段权重 | 中段权重 | 尾段起点 | 尾段末端 | 尾段衰减 |
|---|---|---|---|---|---|---|
| 偶尔聊 | 60–480 分钟 | 0.6 | 1.0 | 1.3 | 0.8 | 0.4 |
| 默认 | 5–240 分钟 | 1.0 | 1.15 | 1.15 | 0.6 | 0.3 |
| 稍微有点粘人 | 5–150 分钟 | 1.5 | 1.2 | 1.0 | 0.45 | 0.25 |
| 粘人 | 3–60 分钟 | 2.0 | 1.3 | 0.8 | 0.3 | 0.2 |

手动改任意一个参数，档位会自动变成「自定义」。

### 曲线怎么读

把「最短间隔 ~ 最长间隔」切成三段：

- **前段**（刚聊完不久）：权重 `early_weight`，有事件时再乘 `early_weight_event`。
- **中段**：权重 `mid_weight`。
- **尾段**：从 `tail_head_weight` 按 `tail_decay_power` 衰减到 `tail_floor_weight`，所以末端最难拖到。

几个常用参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| 最短间隔 | 5 分钟 | 再急也不会比这更短 |
| 最长间隔 | 240 分钟 | 再忙也至少这么久说一句 |
| 最多连续未回复 | 3 次 | 达到后暂停，直到你说话；0 = 不限 |
| 有事件时的前段倍数 | 3.0 | 你在做事时她更爱凑过来 |

面板里改参数，柱形图会**实时重绘**，但只有点「保存」才写进配置。

### 一条规则有什么

- **触发词**：命中即开始这个事件（支持否定前缀，如「不去健身」不会误判）。
- **结束词**：命中即结束，例如「吃完了」「洗完了」。
- **时长**：到点自动过期，过期后按原排程决定是否重抽。
- **加成**：事件有效期内，开口概率乘以这个倍数。
- **加成预算**：`boost` 最多用几次，默认 1；`0` 表示不限次，用完就回到普通节奏。
- **话术**：告诉模型这件事进行到一半时该怎么开口，支持 `{elapsed}`、`{label}` 占位符。

### 语义识别

关键词没命中时，插件会问一次模型「这句话属于哪类事件」。

- **语义识别**：总开关，关掉就只靠关键词，不花 token。
- **语义识别模型**：填 `服务商/模型名` 可以单独指定一个便宜的小模型；留空用当前聊天模型。
- **提示词**：面板「配置 → 内置提示词」里可改，支持 `{{catalog}}` 占位符（会自动插入 16 类事件表）。

为了省调用，插件有一道预筛：句子里没有「在 / 去 / 要 / 正 / 准备 / 得 / 该 / 出门 / 开始」，结尾也不是「了 / 咯 / 啦 / 喽 / 着呢」，就直接跳过。

## 在场状态

### 离开 / 回来

- 命中「出门」「上班」「下楼」「去公司」等离开词 → 标记「不在身边」，并记下时间。
- 命中「到家」「回来了」「到楼下了」等回归词 → 标记回来，之后 10 分钟内的话术是「刚回来」，更黏。
- 离开状态默认 8 小时过期，防止忘了说「到家」导致一直以为你不在。

关键词都在「在场状态」分组里，可以自己增删；留空表示永不标记。

### 在一起

命中同行语义（「一起」「一块」「我们」「咱俩」「陪你」「带你」「跟我」「牵着」「手牵手」「抱着你」「靠着你」「在你旁边」等）时，插件会记一段「在一起」状态：

- **默认 150 分钟**。如果当时还挂着事件、事件结束得更晚，就跟着事件走，最长不超过 2 倍（300 分钟）。
- 在一起时，她**不会**说「想你」「等你回来」「到哪了」「给你留着位置」这类暗示你不在的话，而是直接说眼前的事：手、座位、吃的、下一步去哪。
- 说「到家了」「回来了」会自动清掉「在一起」。
- 面板任务页有「设为在一起 / 取消在一起」，可以手动切换。
- 「一起出门」不会被判成「你一个人走了」；「我跟朋友去吃饭」也不会被误判成在一起。

> 时长目前在代码里固定 150 分钟，还没有开放到配置页。

## 加速事件

你说「快到家」「马上到」「在路上了」这类话时：

- 如果当前是「在路上」或「出门办事」类事件，会临时提高加成并缩短剩余等待，让她更早开口。
- 只对出门类事件生效；在「吃饭」「洗澡」里说「快好了」不会触发。
- 一句话同时命中加速词和结束词（比如「快吃完了」）时，按加速处理，不会把事件直接结束。

触发词、加速倍数（上限 10）、剩余时长缩短系数都可配。

## 睡眠与提醒

### 三个开关

| 功能 | 默认 | 说明 |
|---|---|---|
| 晚睡提醒 | 开 | 在 23:00–00:20 窗口内催一次 |
| 午睡提醒 | 开 | 独立开关，13:00–13:30 窗口内催一次 |
| 到点自动提醒 | 开 | 关掉后只有你说「等会睡」才会排提醒 |

### 等会再睡

你说「待会睡」「再看会手机」「再躺会」时，插件会在 20–60 分钟的区间里按权重抽一个点，单独排一次提醒，不受晚睡窗口限制。

### 免打扰

- 说「睡了」「晚安」「要睡了」→ 进入免打扰，直到起床时间（默认 08:00）。
- **只有命中唤醒词才解除**。默认 7 个：`我醒了 / 睡醒了 / 醒了 / 起床 / 起来了 / 不睡了 / 睡不着`。
- 唤醒词在「作息与词表」里可改，逗号分隔。
- 睡前闲聊（「笨笨的」「mua」）不会把她吵醒。

### 时间参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 晚睡窗口 | 23:00–00:20 | 支持跨天 |
| 午睡窗口 | 13:00–13:30 | 建议 20–40 分钟 |
| 起床时间 | 08:00 | 免打扰结束点 |
| 夜晚起点 | 18:00 | 之前算白天补觉，之后算晚睡 |
| 补觉静音 | 8 小时 | 白天说「睡了」后静音多久 |
| 等会睡提醒区间 | 20–60 分钟 | 反了会自动对调 |

同一窗口只催一次；两条提醒之间至少隔 90 分钟，避免刚催完又催。

## 上下文注入

她开口前要看一点上下文。三种模式：

| 模式 | 开关 | 说明 |
|---|---|---|
| 会话历史 | 用会话历史 = 开 | 用 AstrBot 当前会话的完整历史 |
| 平台流水 | 用平台流水 = 开 | 从平台消息记录里取最近 N 条，按时间排 |
| 两者都用 | 两个都开 | 上下文最全，也最费 token |

两个都关时会自动回退到会话历史，不会让她「失忆」。

- **流水条数**：默认 20，0 表示不注入。
- **包含 Bot 自己的话**：默认开。
- **流水提示词**：支持 `{{platform_history_lines}}`、`{{current_time}}`、`{{unanswered_count}}`。

主动消息提示词支持 `{{current_time}}`、`{{unanswered_count}}`、`{{event_hint}}` 三个占位符；`{{event_hint}}` 就是上面「在场 / 事件 / 在一起」算出来的那段提示。

面板里改的提示词存在 `data/plugin_data/astrbot_plugin_mitchell_minichat/web_overrides.json`，不进 AstrBot 原生配置，改完立即生效。

## 省 token（只影响主动消息）

主动消息是插件直连模型，不经过 AstrBot 的请求流水线，所以这里单独给三个开关；**正常回复不受影响**。

| 开关 | 默认 | 作用 |
|---|---|---|
| 读历史图片 | 关 | 主动消息不再带历史图片，只留文字 |
| 带历史思考块 | 关 | 剔掉她以前回复里的 think，只留说出口的话 |
| 启用上下文窗口 | 关 | 打开后按「最近 N 条 / N 小时 / 至少 N 条」裁剪；关掉全量发送 |

- 条数和小时都是上限，谁先到算谁；「至少保留」是兜底，且不会超过条数上限。
- 时间从消息里的 `<system_reminder>Current datetime: YYYY-MM-DD HH:MM (时区)` 解析；它由 AstrBot 的「注入当前时间」（`datetime_system_prompt`）写入，关掉后窗口会退化成只按条数裁剪。
- 窗口只影响主动消息；正常对话仍由 AstrBot 自己管理上下文。
- 关掉开关立刻恢复原样，不需要重载插件。

## 智能分段

把一条长回复拆成几条短气泡，模拟真人打字。

| 参数 | 默认 | 说明 |
|---|---|---|
| 启用分段 | 开 | 总开关 |
| 智能分段 | 开 | 保护引号、括号、代码块不被切断 |
| 最多几段 | 5 | 3–7 最像真人 |
| 最小段长 | 12 字 | 太短的段会并回去 |
| 分段标点 | `[。.？！?!\n…～]+` | 一般不用改 |
| 延迟策略 | random | random / linear / log / fixed |
| 随机延迟 | 0.8–3.0 秒 | random 策略用 |

> 分段标点那个正则在面板里手改会被二次转义，除非你清楚自己在做什么，否则别动。

## Web 面板

### 两条通道

- **AstrBot 插件页**：插件卡片里的「主动私聊Mini」页面。
- **独立面板**：`http://127.0.0.1:7627`，适合本机长期开着。

相关配置：`enable`（启用）、`host`（默认 127.0.0.1）、`port`（默认 7627）、`password`（默认空）、`allow_embed`（默认关）。

### 任务页

每个会话一张卡片，显示下次触发、未回复次数、当前事件、在场、睡眠，以及这些按钮：

| 按钮 | 作用 |
|---|---|
| 生成预览 | 只生成不发送，用来试语气 |
| 立即发送 | 跳过排程，马上发一条 |
| 重新排程 | 按当前曲线重抽下一次时间 |
| 重置计数 | 未回复次数清零 |
| 清除事件 | 结束当前事件 |
| 清除睡眠 | 清掉睡眠免打扰 / 待睡 / 已提醒状态 |
| 设为在一起 | 手动标记「她就在你旁边」 |
| 取消在一起 | 清掉在一起状态 |

另外还有「新增会话 / 移除会话」。

### 概率页

四张柱形图：无事件时、事件生效时、晚上睡觉、白天补觉。

- 拖动权重或间隔，图会实时重绘，**不保存**；点「保存」才写入。
- 「纵轴封顶」默认 20%，四张图共用一个上限，纯显示用，改完不用重载。

### 配置页

- 常用参数直接改，保存即生效。
- 事件规则可以增删改，改完需要重载插件。
- 内置提示词（语义识别、催睡话术）只在面板里，不进原生配置页。

### 安全

默认只监听 `127.0.0.1`，且没设密码。要放到局域网或公网访问，务必：

1. 把 `host` 改成 `0.0.0.0`；
2. **设置密码**；
3. 保持 `allow_embed = false`（防点击劫持）。

## 常见问题

**Q：为什么不主动说话？**
依次检查：插件是否启用、「监听的会话」是否填对、`enable_weighted` 是否被关、日志里有没有「采样 xx 分钟」。达到「最多连续未回复」也会暂停（任务页显示 `paused`），你回一句就恢复。

**Q：面板上的 paused 是什么意思？**
连续未回复达到上限后，插件暂停主动消息，任务页会显示 `paused`（之前会误显示成 due / scheduled）。你回一句就恢复。

**Q：事件识别不准？**
关键词是子串匹配 + 否定前缀过滤。没命中时会走语义识别。可以补触发词，或把「语义识别模型」换成更听话的小模型。

**Q：说「快到家了」会怎样？**
在「出门 / 在路上」事件期间说「快到家了 / 快到了 / 马上到」，会保留事件并叠加加速（默认 ×3，上限 ×10），有效期砍半；这时仍算他在外面，话术会变成「去门口接 / 饭别凉了」。真说「到家了」才会清掉事件和在场状态。

**Q：为什么她说「想你」？**
说明当时没有「在一起」状态，而且可能挂着「在约会 / 出门」类事件。说一句「牵着手呢」「我们一起」就会切到在一起；也可以在任务页点「设为在一起」。

**Q：面板显示「在身边」和「在一起」有什么区别？**
「在身边」只是没有离开记录，属于默认值；「在一起」是明确知道你在旁边，话术会主动避开「想你 / 等你回来」。

**Q：分段没生效？**
确认「启用分段发送」开着；如果回复本身很短（低于最小段长），不会被切。

**Q：配置页看不到「省 token」？**
先 Ctrl+F5 硬刷新；确认打开的是 `http://127.0.0.1:7627`，而不是 AstrBot 原生配置页（原生页里这 6 个开关在「上下文注入」里）。

**Q：改了配置不生效？**
大部分保存即生效。事件规则、面板地址、端口需要重载插件；面板上会提示。浏览器里的旧界面用 Ctrl+F5 硬刷新。

**Q：为什么没催我睡觉？**
检查对应开关、窗口时间、起床时间；同一窗口只催一次，两次提醒之间至少隔 90 分钟。说「晚安」进入免打扰后也不会再催。

**Q：说「我午睡了」为什么没进免打扰？**
现在会区分场景：「午睡 / 睡午觉 / 补觉 / 眯一会」按「在午睡」事件处理，不开整夜静音；疑问句（睡了吗 / 你睡了没）和第三人称（孩子睡了 / 我妈睡了）也不算你要睡。只有「我睡了 / 晚安 / 睡觉了」这类明确宣告才进免打扰。

**Q：插件市场里版本还是旧的？**
