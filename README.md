# 主动私聊Mini（astrbot_plugin_mitchell_minichat）

一个为 AstrBot 打造的**轻量主动私聊插件**：让机器人不用你招呼，自己挑时机凑过来开口，语气像真人一样自然。

支持平台：aiocqhttp、qq_official、Telegram、企业微信、飞书、钉钉、KOOK。

## 它做什么

- **主动开口**：按加权概率曲线自动挑时机给你发消息，不再是死板的固定间隔。
- **知道你在干嘛**：识别你在吃饭、做饭、洗澡、开会、学习、看电影等 16 种状态，每类事件的"开口倾向"和"话术"都不一样。
- **懂你在不在**：你说"出门了"她会当你不在，说"到家了"她立刻贴回来。
- **催你睡觉**：晚睡、午睡两个提醒窗口，还能应你说"等会睡"单独排一次提醒。
- **像人一样说话**：自动把长消息切成几条短气泡，中间停几秒，像真人一句句打出来。
- **自带网页面板**：一个网页里搞定所有配置，改参数还能实时看柱形图预览，不用重启。

## 安装

1. 把本插件文件夹放进 AstrBot 的 `data/plugins/` 目录，或从插件市场搜索安装。
2. 重启 AstrBot，在「插件管理」里启用「主动私聊Mini」。
3. 在插件配置页的「监听的会话」里填入要服务的会话（格式 `机器人名:FriendMessage:QQ号`，可发 `/sid` 快速获取）。

> 仅私聊生效，不支持群聊。

## 配置入门

打开插件配置页（AstrBot 插件卡片，或插件自带的独立面板 `http://127.0.0.1:7627`）。

### 聊天频率（概率页）

四个档位一键切换：

| 档位 | 间隔范围 | 特点 |
|---|---|---|
| 偶尔聊 | 60–480 分钟 | 少打扰，拖后开口 |
| 默认 | 5–240 分钟 | 平衡的节奏 |
| 稍微有点粘人 | 5–150 分钟 | 比默认黏一点 |
| 粘人 | 3–60 分钟 | 频繁、更快开口 |

也可以手动拖「区间前段/中段/尾段」的权重，柱形图会**实时预览**（不保存），点「保存」才生效。

### 事件规则

预设了 16 类事件：在吃饭、在做饭、在喝东西、在路上、在开会、在忙、在洗澡、在打游戏、在忙家里的事、在学习、看电影、约会、逛街、看病、运动、午睡。

每条规则都有：
- **触发词**：命中即认为你开始了这件事
- **结束词**：命中即认为这件事做完了
- **话术（hint）**：教她这件事进行到一半时该用什么语气开口

### 在场状态 & 加速事件消息

- **离开/回家关键词**：命中"出门"标记你不在，命中"到家"标记你回来。
- **加速事件消息**：你说"快到家"这类话时，如果正处在「在路上/出门办事」事件里，会临时把她的开口概率提前、缩短等待。只对出门类事件生效。

### 睡眠提醒

三个独立开关：
- **晚睡提醒**：在设定窗口（默认 23:00–00:20）内催一次
- **午睡提醒**：午睡窗口（默认 13:00–13:30）内催一次
- **等会再睡**：你说"待会睡/再看会手机"，按区间和权重单独排一次提醒

说"晚安/睡了"会立即进入免打扰，直到起床时间。

### 内置提示词（配置页）

- **语义识别提示词**：教模型判断你的话属于哪类事件（支持 `{{catalog}}` 占位符）
- **提醒睡觉话术**：教她催睡觉时的语气（支持 `{{time}}` 占位符）

## 常见问题

**Q：为什么不主动说话？**
检查「启用插件」和「监听的会话」是否配好；确认「启用加权采样」没关；看日志里有没有采样记录。

**Q：事件识别不准？**
关键词是纯子串匹配（带否定前缀过滤），没命中时会走「语义识别」问模型。可以补充触发词，或调「语义识别用的模型」。

**Q：分段没生效？**
确认「启用分段发送」开着；分段标点默认含句号/问号/感叹号/换行，别在面板里手改那个正则（保存会二次转义）。

**Q：改了配置不生效？**
大部分配置保存即生效；事件规则、面板地址等改动需要重载插件。面板会提示。

## 测试

插件核心逻辑均可离线测试（不依赖真实消息）。测试脚本通过 Dummy 子类 + 假时钟 + 内存 Store 直接调用纯函数，覆盖采样、事件匹配、睡眠状态机、分段等。
